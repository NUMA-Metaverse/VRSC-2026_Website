# 全国学生VRサークル活動報告大会 2026 — 募集サイト

## 目的と構成

学生団体の活動報告・VR/XR制作発表への参加に関心を持ってもらうためのサイト。

1. Hero — 2026キービジュアルを画面幅いっぱいに表示。その下に参加・応募への導線、続けて活動写真の自動スクロール帯を配置。画像上に説明文やボタンを重ねない。
2. About — 大会の目的、活動写真のコラージュ、活動共有・制作・交流の紹介
3. Entry — 大会紹介との間に2本目の写真帯を配置。その下に団体登壇と制作発表の募集案内、一般参加の案内予告。募集案内の直後に3本目の写真帯を配置
4. Archive — 2025・2024・2023・2022年の大会サイトへのリンク
5. Footer — 大会名、ページ上部へ戻るリンク

参加団体一覧・作品一覧・ゲスト・当日の予定・会場は現在のページには表示しない。
2025年度の参考データは将来の更新用に保持し、未使用コンポーネントは置かない。

## デザイン

- public/event-2026/1.png は縦横比を保って画面幅いっぱいに表示。切り抜き・傾き・追加の枠や文字を加えない。
- 今年の素材に合わせた赤 #e73d35、黄色 #f1f15b、黒 #171717、紙色 #f7f5ec。
- 太い日本語見出し、黒い輪郭と影、網点、斜めの写真枠でポスター風に統一。
- public/images の25枚を、`data/activityPhotos.ts` で9枚・8枚・8枚の重複しない3組に分ける。メイン下は左向き、募集案内前は右向き、募集案内後は左向きに途切れなく流す。動きを減らす設定では自動再生せず手動スクロール。大会紹介にはコラージュも使用し、2026年の参加団体一覧として扱わない。
- スマートフォンではキービジュアルを先頭に置き、募集カードを1列で表示。
- キーボードフォーカス、本文へのスキップ、アンカーのヘッダー余白、動きを減らす設定に対応。

## 募集情報の更新

`data/recruitment.ts` に2種類の募集内容を集約。
`href` 未設定時は「募集詳細は近日公開」を通常のテキストとして表示。
応募開始時は `href` にフォームURLを設定し、`note` に確定した条件や締切を記載する。
`components/EntryCTA.tsx` の共通ステータスも募集状況に合わせて更新する。
フォームURL、応募資格、締切、発表形式が未確定の間は具体的条件を創作しない。

## OGP

Open Graph・Xのカードには、指定の `public/ogp.png` をそのまま使用。
`app/layout.tsx` の寸法は実ファイルに合わせて7680×4320。
本番の絶対URLは `NEXT_PUBLIC_SITE_URL` から取得し、カスタムドメイン `https://vrsc-2026.numa-meta.com` を使用する。サイトはドメイン直下に配置し、`basePath` は設定しない。

## 確認

- `npm run build`
- `npm run lint`
- PC・スマートフォンで画像・レイアウト・ページ内リンクを確認

## 表記・文体

- 運営団体は確定情報がないため掲載しない。
- 見出し・説明文は大会内容や募集内容を具体的に伝える。ポエム調のコピーやスローガンは追加しない。
- 小さい装飾用の英語、英語の繰り返し帯、独自に作ったロゴ風マークは使用しない。
- 支給された2026キービジュアルはそのまま使用する。

## 参考サイト

- [Sanrio Virtual Festival](https://v-fes.sanrio.co.jp/)：大きなキービジュアルと目立つ参加導線の配置を参考にする。
- [バーチャルマーケット2025 Winter](https://vket.com/lp/2025Winter)：画像中心の構成と、参加目的に合わせた導線を参考にする。
- 写真帯の前に参加案内を配置し、大会紹介内の「募集案内を見る」は重複するため置かない。

## 動き

- Motion for React（旧Framer Motion）13.2.0を使用。導入時のnpm最新安定版を確認し、バージョンを固定。
- メインビジュアルは初回に短くフェードしながら原寸表示へ。スクロールに合わせて参加案内、大会紹介、写真、募集カードが一度だけ現れる。
- 参加案内ボタンはホバーで少し浮き、押した時に縮むスプリングアニメーション。
- 写真帯は既存のCSSによる連続スクロールを維持する。
- 本文はサーバー描画時から表示し、JavaScriptなしでも内容やリンクを利用できる。動きを減らす設定ではMotionの移動・拡大も停止する。
- 公式ドキュメント：[インストール](https://motion.dev/docs/react-installation)、[useAnimate](https://motion.dev/docs/react-use-animate)、[useReducedMotion](https://motion.dev/docs/react-use-reduced-motion)。
